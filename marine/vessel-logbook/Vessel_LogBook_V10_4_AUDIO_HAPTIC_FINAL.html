Method / Reference

QMD = (F + 6M + A) / 8. First trim correction uses trim, TPC, LCF and LBP. Second/Nemoto correction uses the MCTC difference around the QM draft. Density correction references 1.025 t/m³. Net displacement is corrected displacement minus deductibles; cargo is the initial/final net-displacement difference according to the selected operation mode.

Excel Compatibility Notes

This tool is offline-only and never contacts the internet. The Excel Editor opens real .xlsx/.xlsm files only if xlsx.full.min.js is manually placed next to this HTML file — there is no automatic download. Without that file, use Data → Export Excel Summary instead, which needs nothing extra and always works. XLSM VBA projects can be preserved on save when the engine is present, but macros are never executed. This editor does not pretend to be Microsoft Excel and cannot guarantee every Excel feature.
