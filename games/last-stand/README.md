# Last Stand

**Status:** USABLE / OFFLINE HTML5 GAME

Dependency-free endless auto-defense strategy game delivered as one HTML file.

## Gameplay

- your base fires automatically
- upgrade damage, fire rate and economy
- choose a tactical perk every 5 waves
- boss encounter every 10 waves
- enemy health, speed and density scale over time
- best wave is stored locally in the browser

## Run

Open `index.html` directly in Chrome, Samsung Internet, Firefox, or a capable HTML viewer. No server or internet connection is required.

## Migration audit

The recovered JavaScript was syntax-checked successfully. The game has no external runtime dependencies, making it appropriate for the Projects repository.

Touch/click the three upgrade buttons and tactical choices to play.
