# BlazeSystems Arcade

**Status:** USABLE / PORTABLE HYBRID  
**Canonical recovered build:** Portable Hybrid

A browser-based offline/portable arcade project evolved from the earlier Friv-style launcher and SNES/MULTIEMU experiments.

## Reconciliation result

The Portable Hybrid artifact is the newest recovered consolidated build. Earlier Friv Offline Arcade, SNES playable/UI, MULTIEMU, PHP/server, and hybrid iterations are treated as lineage rather than current releases.

## Features

- single-file portable HTML delivery
- game library / launcher UI
- local browser storage for preferences and game state where supported
- keyboard and pointer/touch controls
- integrated browser-game content and emulator-oriented experiments from the project lineage

## Run

Open `BlazeSystems_Arcade_PORTABLE_HYBRID.html` in a modern browser.

Some browser/emulator features can still depend on browser security rules, cached resources, or the formats being loaded.
