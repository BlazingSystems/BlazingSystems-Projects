# DraftSight Trainer

**Status:** FINAL / AUDITED  
**Canonical recovered build:** V5

Offline single-file training simulator for practicing vessel draught-mark reading under animated sea conditions.

## Reconciled features

- configurable ready/countdown delay before input becomes active
- timed scoring and maximum-reading-time threshold
- automatic next-scenario flow
- keyboard shortcuts for commit/new scenario
- persistent settings across reloads
- mark designer, results, guide, and trainer views
- audited V5 build selected over V2–V4 and earlier "Final" variants

## Run

Open `DST_DraftSight_Trainer_V5_Final_Audited.html` in a modern browser. No server is required.

## Audit status

The V5 artifact is the latest recovered audited build. Older variants are intentionally not presented as the canonical release; they belong in Archives for history.

## Limitations

This is a training simulator, not an approved marine surveying instrument. Always follow vessel/company procedures for operational draught surveys.
