# Captive Portal UI Demo

**Type:** Networking user-interface study  
**Status:** Standalone portfolio demo

A generic captive-portal front end demonstrating plan selection, voucher entry, session feedback, and pause/resume interaction.

## Public Version

This build is intentionally detached from any commercial PisoWiFi/hotspot product and does not contain production endpoints, reverse-engineered request paths, customer configuration, credentials, or deployment-specific values.

The entire demo runs locally in the browser and sends no network requests.

Open `index.html` directly in a browser.
