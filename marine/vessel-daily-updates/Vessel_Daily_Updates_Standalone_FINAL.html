How the calculations work

Todate = Previous + Today

Todate Trips = Previous Trips + Today Trips

Balance = Total Cargo − Todate

For loading jobs, the same progress formula is used: previous plus today's loaded quantity. For discharging, today's figure is the discharged quantity.
