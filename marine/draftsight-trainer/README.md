# Draft Reading Trainer

**Type:** Offline training application  
**Status:** Working portfolio build

A generic browser exercise for practicing visual estimation of a waterline against a simulated draft scale.

## Features

- randomized waterline scenarios;
- numeric answer entry;
- configurable-style tolerance logic;
- immediate result feedback;
- no external dependencies.

## Scope

This is a training illustration only. It does not reproduce a company-specific simulator, vessel drawing, survey form, or proprietary marking template.

Open `index.html` directly in a browser.
