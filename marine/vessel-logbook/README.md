# Marine Operations Logbook

**Type:** Offline web application demonstration  
**Status:** Portfolio demo

A generic browser-based operations logbook that demonstrates offline reporting workflows without publishing any real employer, client, vessel, terminal, or shipment records.

## Demonstrated Functions

- job setup and reference information;
- daily quantity and trip updates;
- chronological event log;
- simplified draft arithmetic;
- browser-local persistence;
- responsive desktop and mobile layout.

## Public Demo Policy

All sample records are fictional. The public build uses an original generic interface and does not reproduce any company logo, official form, document-control code, proprietary workbook, or operational dataset.

## Run

Open `index.html` in a modern browser. No server is required.

## Validation Boundary

Calculation features are educational demonstrations. Operational marine surveying requires vessel-specific data, approved procedures, and independent verification.
