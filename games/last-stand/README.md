# Last Stand

**Type:** Offline HTML5 strategy game  
**Status:** Working build

A lightweight endless-defense game built as a single browser file with no external runtime dependencies.

## Gameplay

- automatic base defense;
- damage, fire-rate, and economy upgrades;
- tactical perk choices;
- progressive enemy scaling;
- periodic boss waves;
- locally stored best-wave record.

## Technical Characteristics

- dependency-free HTML/CSS/JavaScript;
- no external scripts, assets, or network requests;
- works directly from a local file;
- keyboard/touch-friendly browser interface.

## Run

Open `index.html` in a modern browser.
