# Vessel Daily Updates

**Status:** USABLE / STANDALONE

Offline single-file helper for preparing vessel daily-update text and operational summaries.

The recovered `Vessel_Daily_Updates_Standalone_FINAL.html` is the latest standalone artifact found in the Library and is kept separate from the larger Vessel LogBook because it is useful as a focused tool on its own.

## Run

Open the HTML file directly in a modern browser. No server is required.

## Privacy

Do not commit real vessel/customer/job records to this repository. The public repository contains the tool only.
