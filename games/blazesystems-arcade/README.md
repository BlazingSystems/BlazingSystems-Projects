# BlazeSystems Arcade

**Type:** Browser game / launcher interface study  
**Status:** Public demonstration build

The public portfolio edition demonstrates the launcher concept with an original built-in mini-game.

## Public-Safe Scope

This edition intentionally does **not** bundle:

- commercial ROM files;
- copied game assets;
- emulator cores;
- third-party game code;
- copyrighted console BIOS files.

The demonstration focuses on the user-interface concept, local browser execution, keyboard controls, and a lightweight arcade experience.

Open `index.html` directly in a browser.
